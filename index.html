🚀 Automação Instagram

Fluxo recomendado: analisar → decidir → roteirizar → prompt → vídeo → aprovação → postar
  1. Coletar métricas de posts/Reels autorizados pela API oficial.
  2. IA escolhe ângulo, gancho, formato, duração e CTA.
  3. Gerar roteiro curto e transformar em prompt VEO.
  4. Gerar vídeo em ferramenta externa e salvar URL pública do arquivo.
  5. Publicar via Instagram Graph API somente em conta profissional aprovada.
⚠️ O navegador não deve guardar token secreto nem senha do Instagram. Use este gerador para criar o plano JSON e execute a publicação em um backend/n8n/Make com OAuth e aprovação humana opcional.
